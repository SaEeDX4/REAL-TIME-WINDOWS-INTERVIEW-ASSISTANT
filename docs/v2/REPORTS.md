# Post-Interview Reports

Built by `ReportBuilder` from `SessionMemory` + the target's prepared pack + session metrics; rendered by `HtmlReportRenderer` (self-contained HTML, CSP `default-src 'none'`, all content HTML-encoded, `<bdi dir=auto>` for mixed RTL/LTR text, `dir=rtl` for Arabic/Persian). Print → PDF via the OS (no PDF library → no licence risk).

Sections: questions asked (original wording + detected language + category/mode as language-neutral meaning), suggestions shown, category counts, difficulty areas*, stories & metrics recommended (with counts), repeated topics, job topics not covered*, experience-gap questions, interruptions/fast follow-ups (estimated, with confidence), latency P50/P95, transcription notes, strengths* and gaps* of the preparation, follow-up preparation*, thank-you themes*, relevant stories not used. (* labelled **Inference**.)

Honesty: with the candidate microphone OFF (only mode implemented) the report states it records questions and suggestions, **not** what the candidate said, and is not an assessment of spoken performance. No success probabilities or hiring scores are produced.

Report language is selectable independently of interview languages (labels for all 10 languages; native review pending). Original interviewer wording is never translated in place. Machine translation of questions into the report language: **NOT IMPLEMENTED** (category/intent provide the normalized meaning).
