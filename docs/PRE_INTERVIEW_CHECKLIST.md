# Pre-interview checklist (5 minutes)

1. **Headset connected** and selected in Windows *and* in Google Meet (Meet → Settings → Audio → Speakers).
2. Start `InterviewAssistant.exe`. Click the ✓ icon → **Pre-interview check** → **Run checks**:
   - Knowledge: `TEROXX / XAB LOADED`
   - API key: `SET`
   - Answer service: `READY`, Latency test: `PASS`
   - Transcription: `READY`
   - Audio: play a YouTube video in Chrome → `ACTIVE`
3. In Settings, if the level bar doesn't move, pick the **exact headset** instead of "System default". Bluetooth headsets often expose two devices ("Headphones" and "Headset/Hands-Free") — choose the one Meet uses.
4. **Start interview** → status `● LISTENING`.
5. Test: type `How would you increase XAB adoption?` in the bottom box → bullets appear instantly.
6. Position the window near the camera, Compact mode on, font **Large**.
7. Fallback if anything fails mid-call: type the question (`Ctrl+Alt+Q`, Enter). Prepared answers work even offline.

**Questions you can ask them** (also under "Do you have any questions for us?" → *Full answer*):
- How do you currently define success for the XAB ecosystem?
- What's the biggest product problem you'd want this role to solve in the first six months?
- How do Product, Engineering and Compliance work together when a new reward or token mechanic is designed?
- How is the internal ledger and reconciliation set up today, and where are the pain points?
- How do clients experience XAB and the Lite/Silver/Gold/Platinum levels today?
- Which XAB metrics does leadership review regularly?
- How is the roadmap balanced between XAB and other Teroxx products?
- What does the engineering team look like, and how do you run delivery?
- How do you see XAB evolving under MiCA?
- What would make someone exceptional in this role after a year?

**Before the call, re-read:** the live job posting and the current Abloxx whitepaper (`knowledge/role_brief.md`, `knowledge/whitepaper_notes.md` list what to verify).
